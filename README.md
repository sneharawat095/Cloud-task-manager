# Cloud Task Manager

Dockerized Node.js Task Manager Application

## Features
- Add, Delete, View Tasks
- Docker Support
- Ready for IBM Cloud Deployment

## Tech Stack
- Node.js
- Express
- Docker

## How to Run
1. `docker build -t task-manager .`
2. `docker run -p 3000:3000 task-manager`

## Deployed on
IBM Cloud Code Engine
